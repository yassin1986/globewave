# GlobeWave live-player test

This is the isolated test branch `globe-player-test-20261114`; it is not the unpublished full directory on `main`. The English, French and Arabic pages now use one responsive YouTube embedded player with nine broadcaster-branded stream choices. The player uses YouTube's own controls and privacy-enhanced embed host. It does not extract HLS URLs, rehost feeds, or use unofficial IPTV lists.

The nine YouTube video IDs returned public oEmbed title/author metadata when checked. That is not a guarantee that a stream is live at every moment, playable in every country/device, or enabled for every viewer; YouTube or the broadcaster may require sign-in, block an embed, change an ID, or end a livestream.

No site advertising has been enabled. YouTube's published help says revenue from ads inside an embedded YouTube player goes to YouTube and the video owner, not the host website. Commercial use of a stream-led directory needs a suitable license or other rights/terms; no free commercial permission for these feeds was verified. Radio and direct HLS playback remain disabled until a station authorizes them.

The weather search remains on the page with attribution to Visual Crossing. Pages retain `noindex,nofollow` while this test is isolated. The main directory branch was not changed.
